# Primeras lecciones de Programación Orientada a Objetos

Este paquete contiene una lección en Markdown y ocho imágenes educativas diseñadas para estudiantes de 17 a 25 años.

Abra el archivo:

```text
Tema_1_Primeras_Lecciones_POO.md
```

No separe el archivo Markdown de la carpeta `imagenes`, porque los enlaces son relativos.
